# beanmatch

![test](https://github.com/otamesi0000/beanmatch/actions/workflows/test.yml/badge.svg)

コーヒーの味の好みから、好みに近い珈琲豆を一致度つきで出力するコマンドです。
1件だけ調べるときは好みを引数で渡し、複数人の好みをまとめて調べるときは1行1件のデータとして標準入力から流し込みます。

## インストール

```
$ git clone https://github.com/otamesi0000/beanmatch.git
$ cd beanmatch
$ ./beanmatch -h
```

Python 3 の標準ライブラリだけで動きます。追加のパッケージは不要です。

## 使い方

### 1件だけ調べる（引数）

好みを `項目=値` の形で引数に並べます。

```
$ ./beanmatch 苦味=5 コク=5
ベトナム・ロブスタ	100
```

### まとめて調べる（標準入力）

引数を付けずに実行すると、標準入力の1行を1件の好みとして読み、1行ごとに結果を出力します。
好みを1行に1件ずつ書いたファイルを用意します。

```
$ cat prefs.txt
酸味=4 香り=5           # 自分
苦味=4 コク=4           # 友人A
酸味=2 甘み=5           # 友人B
酸味=5 苦味=1 香り=4    # 友人C
```

このファイルを標準入力から渡すと、1行ごとに最も好みに近い豆が出力されます。

```
$ ./beanmatch < prefs.txt
エチオピア・シダモ	100
コロンビア	82
ブラジル	82
エチオピア・イルガチェフェ	86
```

引数と標準入力の両方がある場合は、引数を優先し、標準入力は読みません。

## 好みの書き方

- 1件の好みは、`項目=値` を空白区切りで並べて書きます。
- 値は 1（弱い）から 5（強い）までの整数です。
- 指定しなかった項目は判定に使いません。
- 標準入力では、空行と `#` 以降はコメントとして無視します。

使える項目は次の5つで、英語と日本語のどちらでも指定できます。

| 項目（英語） | 項目（日本語） | 意味 |
|---|---|---|
| `acidity` | `酸味` | 酸味の強さ |
| `bitterness` | `苦味` | 苦味の強さ |
| `body` | `コク` | 口当たりの重さ |
| `sweetness` | `甘み` | 甘みの強さ |
| `aroma` | `香り` | 華やかな香りの強さ |

## 出力形式

好み1件につき、`豆の名前` と `一致度` をタブ区切りで出力します。
一致度は 0 から 100 の整数で、100 は好みと完全に一致していることを表します。
`-n` で件数を増やした場合は、好み1件ごとに一致度の高い順で続けて出力します。

## オプション

| オプション | 説明 |
|---|---|
| `-n N`, `--number N` | 好み1件につき上位 N 件を出力する（既定: 1） |
| `-r ROAST`, `--roast ROAST` | 焙煎度 `light` / `medium` / `dark` で候補を絞る |
| `-l`, `--list` | 豆のデータをタブ区切りで一覧表示する |
| `-h`, `--help` | ヘルプを表示する |

## 焙煎度について

焙煎度は、生豆をどのくらい深く煎ったかを表します。
`-r` で指定する値と、一般的な呼び方・味の傾向は次のとおりです。

| `-r` の値 | 呼び方 | 味の傾向 |
|---|---|---|
| `light` | 浅煎り | 酸味と華やかな香りが出やすく、苦味は弱い |
| `medium` | 中煎り | 酸味と苦味のバランスがよい |
| `dark` | 深煎り | 苦味とコクが強く、酸味は弱い |

各豆の焙煎度は、その豆でよく使われる焙煎度を割り当てたものです。
同じ豆でも店によって焙煎度は異なります。
各豆の焙煎度は `-l` で確認できます。

## おすすめの淹れ方

出力された豆の焙煎度に合わせた、淹れ方の目安です。

| 淹れ方 | 特徴 | 合う焙煎度 |
|---|---|---|
| ハンドドリップ | ペーパーフィルターに入れた粉にお湯を少しずつ注いで抽出する。注ぎ方やお湯の温度で味を調整しやすい | 浅煎りから深煎りまで |
| サイフォン | フラスコの水を加熱し、上に押し上げられたお湯に粉を浸して抽出する。高温で安定して抽出でき、香りが立ちやすい | 中煎りから深煎り |

ハンドドリップでは、浅煎りは高めの温度（90〜95℃）、深煎りは低めの温度（80〜85℃）のお湯を使うと、それぞれの豆の味が出やすくなります。

## 使用例

上位3件の候補を出す例です。

```
$ ./beanmatch -n 3 酸味=4 甘み=5 香り=5
エチオピア・シダモ	100
エチオピア・イルガチェフェ	80
イエメン・モカ	80
```

浅煎りの豆の中から選ぶ例です。

```
$ ./beanmatch -r light 苦味=5
エチオピア・シダモ	25
```

全員の上位3件に入った回数を数えて、みんなに合いそうな豆を探す例です。

```
$ ./beanmatch -n 3 < prefs.txt | cut -f1 | sort | uniq -c | sort -rn
      2 コロンビア
      2 エチオピア・シダモ
      2 エチオピア・イルガチェフェ
      2 イエメン・モカ
      1 ブラジル
      1 ケニア
      1 グアテマラ
      1 インドネシア・マンデリン
```

深煎りの豆のデータを表示する例です。
列は左から、名前、焙煎度、酸味、苦味、コク、甘み、香りです。

```
$ ./beanmatch -l -r dark
インドネシア・マンデリン	dark	1	4	5	3	3
ベトナム・ロブスタ	dark	1	5	5	1	1
```

## エラー

- エラーメッセージは標準エラー出力に出し、標準出力には結果だけを出します。
- 引数の好みが不正な場合（範囲外の値、不明な項目など）は、何も出力せずに終了ステータス 1 で終了します。
- 標準入力に不正な行がある場合は、その行を読み飛ばして残りの行の処理を続け、最後に終了ステータス 1 で終了します。

```
$ ./beanmatch 酸味=9
beanmatch: 値は1〜5の整数で指定してください: 酸味=9
$ printf "酸味=9\n苦味=5\n" | ./beanmatch
beanmatch: 1行目: 値は1〜5の整数で指定してください: 酸味=9
ベトナム・ロブスタ	100
```

## 豆のデータについて

収録している11種類の豆の各値は、一般的な産地の傾向をもとに作者が付けた主観的な評価です。
同じ産地でも農園、精製方法、焙煎によって味は大きく変わるため、目安として使ってください。
