# beanmatch

![test](https://github.com/otamesi0000/beanmatch/actions/workflows/test.yml/badge.svg)

コーヒーの味の好みを標準入力から受け取り、好みに近い珈琲豆を一致度つきで標準出力に出すコマンドです。

## インストール

```
$ git clone https://github.com/otamesi0000/beanmatch.git
$ cd beanmatch
$ ./beanmatch -h
```

Python 3 の標準ライブラリだけで動きます。追加のパッケージは不要です。

## 入力形式

1行に1つの好みを `項目=値` の形で空白区切りで書きます。値は 1（弱い）〜 5（強い）の整数です。指定しなかった項目は判定に使いません。

| 項目（英語） | 項目（日本語） | 意味 |
|---|---|---|
| `acidity` | `酸味` | 酸味の強さ |
| `bitterness` | `苦味` | 苦味の強さ |
| `body` | `コク` | 口当たりの重さ |
| `sweetness` | `甘み` | 甘みの強さ |
| `aroma` | `香り` | 華やかな香り |

空行と `#` 以降はコメントとして無視します。

## 出力形式

入力1行につき、`豆の名前<TAB>一致度(0〜100)` を一致度の高い順に出力します（既定では1件）。

## オプション

| オプション | 説明 |
|---|---|
| `-n N`, `--number N` | 入力1行につき上位N件を出力する |
| `-r ROAST`, `--roast ROAST` | 焙煎度 `light` / `medium` / `dark` で候補を絞る |
| `-l`, `--list` | 豆のデータ（名前・焙煎度・各項目の値）をタブ区切りで一覧表示する |

## 使用例

```
$ echo "酸味=4 甘み=5 香り=5" | ./beanmatch -n 3
エチオピア・シダモ    100
エチオピア・イルガチェフェ    80
イエメン・モカ    80
```

```
$ echo "苦味=5" | ./beanmatch -r light
エチオピア・シダモ    25
```

複数人の好みをファイルにまとめて集計する例:

```
$ cat prefs.txt
酸味=5 香り=5
苦味=4 コク=5
甘み=4
酸味=4 甘み=5
$ ./beanmatch < prefs.txt | cut -f1 | sort | uniq -c
      1 インドネシア・マンデリン
      2 エチオピア・イルガチェフェ
      1 エチオピア・シダモ
```

## エラー

- 不正な行（範囲外の値、不明な項目など）はエラーメッセージを標準エラー出力に出して読み飛ばし、他の行は処理を続けます。
- 不正な行が1つでもあれば終了ステータスは 1 になります。

## 豆のデータについて

収録している豆の各値は、作者が一般的な産地の傾向をもとに独自に付けた主観的な評価です。同じ産地でも農園・精製方法・焙煎によって味は大きく変わるため、目安として使ってください。
